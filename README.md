# Pro-Filio

A phone-first professional identity platform.

## Vision

**One person. One professional profile. Everything important in one place.**

Pro-Filio is designed to become a single source of truth for professional identity: personal information, education, employment, experience, projects, skills, certifications, achievements, documents, and a unified career timeline.

## Current foundation

- Expo + React Native
- TypeScript
- Dark, mobile-first interface
- Central profile data model
- Dashboard
- Profile
- Career
- Portfolio
- Timeline
- Settings
- Reusable UI components

## Product architecture

```
App
 └── AppShell
      ├── Dashboard
      ├── Profile
      ├── Career
      ├── Portfolio
      ├── Timeline
      └── Settings
```

The product is being built around one principle: enter professional information once, then reuse that data across the app, public profile, timeline, portfolio and future CV/resume generation.

## Planned platform capabilities

- Account and authentication
- Structured profile editing
- Education and employment history
- Projects and portfolio
- Skills and credentials
- Achievements
- Documents
- Privacy and visibility controls
- Public shareable profile
- QR profile
- CV/resume generation and PDF export
- Verification and credential support
- Cloud database and file storage
- Recruiter-facing discovery features

## Development

The repository is currently the application foundation. Backend, authentication, cloud storage, public profile hosting and advanced integrations will be added as the architecture matures.
